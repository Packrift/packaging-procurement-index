# Packrift Packaging Procurement Index

Public owned Packrift procurement-reference corpus generated from the top 1,000 AI-sales SKU records.

## Scope

- 1,000 Packrift SKU records
- 8 workflow pages per SKU
- Index, page-type hubs, SKU index, sitemap, robots, and IndexNow key file

## Count Treatment

This is owned public reference content. Count it as crawlable Packrift URL-scale mentions and linkable assets. Do not count it as independent referring domains, paid links, third-party endorsements, or directory backlinks.

## Generate

```bash
node generate-procurement-index.mjs
```

Default public URL target:

`https://packrift.github.io/packaging-procurement-index/`
